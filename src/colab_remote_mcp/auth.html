Authorize Google Colab

No separate MCP account is involved. This connection only requests Google Colab authorization; do not retry `colab auth`.

  1. Open Google Colab authorization ↗
  2. Sign in, approve, and copy the code Google shows. There is no direct callback to MCP because the official installed-client config requires Google’s HTTPS code page.

Approval runs your Colab work when you invoke an MCP tool. The server does not grant automatic Google Drive mount consent.

Credentials stay in the server's encrypted keyring volume. They are not the agent's bearer token and aren't returned as code, outputs, or resources. This helper doesn't ask for another OAuth selection.
